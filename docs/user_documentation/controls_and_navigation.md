# Controls & Navigation

This overview describes the interaction possibilities within the Journey Profile Generator.

## View Navigation
The application is divided into three main tabs:
* **Infrastructure View**: Graphical route planning on the map.
* **Parameter View**: Loading data and entering train metadata.
* **Settings**: Configuration of display options (e.g., visibility of points).

## Navigation in Infrastructure View
The map is based on an interactive graphical interface:
* **Panning**: Hold the left mouse button and drag to move the map.
* **Zooming**: Use the mouse wheel to zoom in or out.
* **Track Selection**: Left-click on a track section to highlight the associated Timing Points (TPs).

## Route Interaction
* **Add Point**: Left-click on a Timing Point (TP) to add it to the route.
* **Remove Point**: `Shift + Right-click` on an already selected TP.
* **Timing Details**: Right-click on a TP in the route to configure stop times and point types (STOP/PASS).

## Shortcuts & Quick Actions
* `Ctrl + Z`: Undo the last step in route planning.
* `Ctrl + Y`: Redo a previously undone step.
* **Clear Route**: Button to completely reset the current planning.
